# Installation

The installation instructions are now on the yzma website:

**https://yzma.ai/getting-started/install/**

## Quick start

```shell
go install github.com/hybridgroup/yzma@latest
yzma install --lib /path/to/lib
export YZMA_LIB=/path/to/lib
```
