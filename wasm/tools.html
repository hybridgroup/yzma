Tool calling, in WebAssembly

llama.cpp runs as a WebAssembly module. The program that drives it is Go, compiled by TinyGo, through the pkg/llamawasm package of yzma. The pkg/template package renders the chat template of the model and offers it the tools, and pkg/message parses the tool calls that come back. The page runs no model logic itself.

Two tools are available. get_weather gives the weather of a city, and calculate does arithmetic on two numbers. Both answer from their arguments alone.

A model must be trained for tool calls to make one. A small chat model answers in plain text instead, which the page shows as the answer.
